# Contributing to Orchestra Platform

We welcome contributions to Orchestra Platform, whether it's a bug fix, a new feature, or a documentation update.

## Getting Started
1. Clone the repository: `git clone https://github.com/orchestra-platform/orchestra-platform.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Familiarize yourself with the codebase and the documentation.

## Submitting a Contribution
1. Create a new branch: `git checkout -b my-contribution`
2. Make your changes: `git add .`
3. Commit your changes: `git commit -m 'My contribution'`
4. Push your changes: `git push origin my-contribution`
5. Create a pull request: `github.com/orchestra-platform/orchestra-platform/pulls`

## Code of Conduct
We follow the standard open-source code of conduct, which can be found at https://github.com/orchestra-platform/orchestra-platform/blob/main/CODE_OF_CONDUCT.md
